# Sidebar Background Images

Đặt 1 file ảnh nền (`.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`, `.svg`) vào thư mục này để tự động làm ảnh nền cho menu bên trái trong `StaffLayout`.

- Nếu thư mục chưa có ảnh nào, menu bên trái giữ nguyên màu nền mặc định.
- Nếu có ảnh, hệ thống tự động lấy ảnh đầu tiên (theo tên file) làm nền cho cả thanh menu desktop và mobile.
